# Enhancing WISDEM&reg;

Enhancing wind turbine drivetrain design optimization capabilities in the open-source system engineering framework WISDEM**.

Responsible: [Vasudev Gupta](mailto:vasudev.gupta@ntnu.no)

**WISDEM&reg;: Wind-Plant Integrated System Design and Engineering Model, developed by [NLR](https://github.com/NLRWindSystems/WISDEM)

## Modules

WISDEM&reg; is a family of modules.  From the core modules,
* _DrivetrainSE_  

has been modified the most, with bug-fixes, corrections and enhancements,

which have been closely integrated into the global wind turbine component
* _WindPark_

and the input `yaml` schemas (geometry, modelling and analysis) have been correspondingly updated to compliment the enhancements.

## Installation

Follow WISDEM's direct use or development installation instructions.

1. Install `git` if you don't already have it:

2. Clone this repository

3. Checkout the `master` branch, as all modifications are on this branch

4. Create and activate your `wisdem-env` environment, substituting "wisdem-env" with a different desired name

5. Install `WISDEM`.
